# SimpleTTS

[English](README.md) | [日本語](README.ja.md)

macOS、iPhone、iPad 向けのテキスト読み上げアプリです。システムの音声を使い、文単位の読み上げと移動、0.5〜2.0倍速での再生、読書位置の保存、文ごとのメモに対応しています。

## 動作環境

現在のプロジェクトは macOS 27.0.1 以降、iOS / iPadOS 27.0 以降を対象としています。開発には Xcode 27.2 を使用します。サードパーティ製の Swift パッケージへの依存はありません。

アプリアイコンは `SimpleTTS/AppIcon.icon` です。Icon Composer で開くと、吹き出しと波形の SVG レイヤー、Liquid Glass マテリアル、外観のバリエーションを編集できます。macOS と iOS の共通ターゲットは `AppIcon` をアプリアイコンのソースとして使用し、ビルド時に Xcode がレイヤー構成のアイコンをコンパイルします。

## macOS で実行

Xcode で `SimpleTTS.xcodeproj` を開き、`SimpleTTS` スキームと `My Mac` を選択して実行します。ターミナルからも起動できます。

```sh
./start.sh
```

ビルド済みのアプリがある場合、スクリプトはそれを起動します。ソースコードや署名設定を変更した場合は、再ビルドしてください。

```sh
./start.sh rebuild
```

コード署名なしでローカル実行するには、`NO_SIGN=1 ./start.sh rebuild` を使用します。これは開発用のオプションです。配布用の署名と公証は別途行う必要があります。

## iOS / iPadOS で実行

Xcode で `SimpleTTS` スキームと iPhone または iPad のシミュレータを選択して実行します。コマンドラインからシミュレータ向けにビルドする場合は、次のコマンドを使用します。

```sh
xcodebuild -project SimpleTTS.xcodeproj -scheme SimpleTTS \
  -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath build/DerivedData-iOS \
  CODE_SIGNING_ALLOWED=NO build
```

実機にインストールする場合は、自分の Apple 開発チームとバンドル ID を指定してください。公開プロジェクトには個人のチーム ID を含めていません。

```sh
cp Config/Signing.example.xcconfig Config/Signing.local.xcconfig
```

コピーしたファイルの `YOUR_TEAM_ID` と `com.example.SimpleTTS` を自分の値に置き換えます。`Signing.local.xcconfig` は Git の管理対象外で、`start.sh` が自動的に読み込みます。`xcodebuild` を直接使用する場合は、`-xcconfig Config/Signing.local.xcconfig` を指定してください。Xcode から実行する場合は、ローカルで開発チームを選択し、個人の署名設定の変更をコミットに含めないでください。

## ファイルを読み上げる

**開く…** でテキストファイルを選択するか、アプリにドロップします。読み込めるのは 10 MiB 以下の通常のファイルのみです。HTTP / HTTPS の URL は読み込みません。UTF-8、UTF-16、Shift JIS、EUC-JP などの文字エンコーディングに対応しています。

再生中は文単位で移動できます。一時停止中に **セーブ** を選ぶと現在の位置を保存し、**コピー** を選ぶと表示中の文をコピーできます。iOS ではバックグラウンドでも再生を続けられます。

## 検索

サイドバー上部の **文を検索** に検索語を入力するか、**編集 > 検索 > 検索…**（⌘F）を選択します。入力すると、開いている文書から検索語を含む文が文書内の順序でサイドバーに表示され、一致箇所が強調表示されます。大文字・小文字や全角・半角の違いは区別しません（例：`ＡＰＰＬＥ` は `apple` に一致します）が、濁点の有無は区別します（`は` は `ば` に一致しません）。検索結果を選択するとその文に移動し、再生中であればそこから読み上げを続けます。macOS では ↓ キーで検索欄から検索結果に移動できます。検索欄を空にすると、セーブ一覧が再び表示されます。検索結果は最大 1,000 件まで表示されるため、それ以上ある場合は検索条件を絞ってください。

## メモ

各文に1件のメモを付けられます。メモは複数行で入力できます。現在の文の右上にあるメモボタン、または **メモ一覧 > メモを追加…**（⇧⌘N）から、その文のメモを追加・編集します。メモは文の下に表示され、周辺の文にメモがある場合はメモアイコンが表示されます。空のメモを保存すると、そのメモは削除されます。

メモは文書ごとに保存され、同じファイルを再び開いたときや、保存した位置から再開したときに自動的に読み込まれます。メモはテキストのキャッシュとは独立して、標準化されたファイルパスで識別されます。内容が同じでも、パスが異なればメモは別々に管理されます。同じファイルを編集した場合、内容が一致する文にだけメモが再対応付けされます。対応する文がなくなったメモや、対応先を一意に特定できないメモも保持されます。これらは読み上げ画面には表示されませんが、メモ一覧の末尾に文番号なしで表示され、コピー・書き出し・削除ができます。ファイルを移動したり名前を変更したりすると、別のメモとして管理されます。保存した位置にはメモの識別子が保持されます。メモ機能の追加前に保存した位置には、元のファイルの情報がありません。その位置から再開して追加したメモは、次に元のファイルを開いたときに、そのファイルのメモへ移行されます。その際も、保存した位置から再開できます。

読み上げ画面のヘッダーにある **メモ一覧**、または **メモ一覧 > メモ一覧を表示**（⇧⌘L）を選ぶと、メモが付いた文、メモの内容、最終更新日時が一覧表示されます。行をダブルクリックすると、その文に移動します。**書き出す** で CSV または TSV ファイルとして保存できます。表計算アプリが文字エンコーディングを判別できるよう、BOM 付き UTF-8 で出力します。`=`、`+`、`-`、`@`、タブ、復帰文字で始まるセルには、先頭に `'` を付け、表計算アプリで数式ではなくテキストとして扱われるようにします。

メモ一覧の **読み込み…** から、CSV または TSV ファイルのメモを取り込めます。一覧が空の場合も利用できます。英語・日本語の書き出し用ヘッダーに対応し、列の順序は変更できます。**文（Sentence）** と **メモ（Note）** は必須で、**文番号（Sentence No.）** と **最終更新日（Last Modified）** は省略できます。引用符で囲まれたカンマ、タブ、複数行のメモにも対応しています。取り込み先は文の内容を確認して決定します。まず元の文番号の文との完全一致を確認し、一致しなければ文書内の別の位置で一意に一致する文を探します。文が見つからない場合や対応先を一意に特定できない場合は、取り込み先を選ぶか、その行をスキップします。取り込み先は文の内容や文番号で検索でき、前後の文も確認できます。対応付けを確認して **読み込む** を選ぶと、まとめて保存されます。既存のメモを置き換える場合は、その行で明示的に確認する必要があります。また、同じ文に2件のメモを取り込むことはできません。スキップした行の既存メモは変更されません。不正なファイルや保存の失敗によって、一部のメモだけが取り込まれることはありません。

メモの追加・取り込みは、**文書と履歴を保存** がオンの場合のみ利用できます。

## プライバシー設定

macOS では **設定**、iOS ではツールバーの **プライバシー** を開くと、文書の保存やロック画面への文書名の表示を設定できます。

- **文書と履歴を保存** は初期設定でオンです。開いた文書をアプリの保存領域にコピーし、読書位置、文書名、本文の抜粋、保存日時、文ごとのメモを保持します。オフにすると、新しい文書や履歴の保存が停止し、メモを編集できなくなります。以前に保存したデータは残ります。
- **ロック画面に文書名を表示** は初期設定でオフです。iOS の再生情報にはアプリ名が表示されます。オンにすると、代わりにファイル名が表示されます。
- **保存データをすべて削除…** で、保存した文書、履歴、メモを削除できます。個別のセーブを削除しても、文書の本文やほかの履歴が残る場合があります。

文書の保存がオフでも、音声合成時には一時的な音声ファイルが作成されます。保存場所、削除時の動作、バックアップの詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## ソースコードの配布

公開したい変更をコミットしてから、次のコマンドでソースコードの ZIP ファイルを作成します。

```sh
./scripts/export-source.sh
```

既定の出力先は `build/SimpleTTS-source.zip` です。スクリプトは `git archive HEAD` を使用するため、Git の履歴、未追跡ファイル、ローカルのビルド成果物、調査用の音声ファイルは含まれません。未コミットの変更がある場合や、出力先のファイルがすでに存在する場合は停止します。出力先を変更するには、第1引数に ZIP ファイルのパスを指定してください。

Git リポジトリを公開すると、コミット履歴も公開されます。作業ディレクトリ全体を ZIP にしないでください。ローカル設定や音声ファイルが含まれる可能性があります。

## テスト

macOS で、ストレージ、ファイル読み込み、メモ、プライバシーに関する回帰テストを実行します。

```sh
./scripts/test-storage-import.sh
./scripts/test-reader-privacy.sh
```

テストには一時ディレクトリ内の合成データと、分離された設定ドメインを使用します。通常のアプリデータを変更したり、音声を再生したりすることはありません。
